# 田圃水管理ロボット 部品表（BOM）v7 — 実機確定版

構成: 電極式水位センサ ＋ プレート上スライドゲート（巻き取りドラム式ワイヤー引き上げ）＋ ESP32制御 ＋ ソーラー独立電源
制御: 10分周期スリープ → 起床 → 水位測定 → 状態変化時のみ10秒×6回検証 → ゲート動作
ファーム: v0.3.1

## v6 → v7 の主な変更（実機検証の結果）

| 項目 | v6 | **v7（確定）** | 理由 |
|---|---|---|---|
| 位置の原点出し | 自動ホーミング（閉方向に最大回転→ゼロ点） | **CALIBモード（人が現地登録）** | 繰り出し過ぎでワイヤーが逆巻きになる欠陥。着座検知は電流差が小さく非現実的 |
| ドラム磁石 | 1個（分解能1回転≒126mm） | **4個・90°等配（分解能≒31.5mm）** | 位置分解能が4倍に向上 |
| 電流センサ | ACS712-20A | **ACS712-5A** | 感度185mV/A（20A版の1.9倍）。実電流0.5〜3Aに最適 |
| 降圧コンバータ | 12V→3.3V | **12V→5V（DROK・可変を5.06Vに調整）** | ESP32は5VピンからLDO経由で給電 |
| 手動SW | 防水・ボックス外面 | **非防水・ボックス内蔵** | 操作時は開ける運用。貫通部を減らし防水を単純化 |
| 電極支柱 | VP13独立3本 | **木製床材ベース＋ビニールテープ絶縁** | 溝付き床材で位置決めが容易。テープで面ごと絶縁しリーク経路を断つ |
| 信号ケーブル | 4芯 | **3芯（GND/上/下）** | 予備芯を省略。2芯は回路が閉じないため不可 |
| 生存確認 | （なし／心拍LED案） | **BOOTボタンで即時起床→LED点灯** | ENはハードリセットでRTCメモリが消えCALIBに落ちる |
| ボックス | 300×400級 | **WB-2AOJ（内寸 縦300×横200×深100）** | バッテリー縦立て＋ドラム上部配置で成立 |

## 動作フロー（v0.3.1確定）

### 通常運用
1. **10分ごとにタイマー起床**（またはBOOTボタンで即時起床）
2. **LED点灯＝5秒の操作受付ウィンドウ**。この間に手動SWが倒されていれば即実行して再スリープ
3. SW操作がなければ電極を測定 → 現在のゲート状態と要求が食い違うときのみ**検証モード（10秒×6回）**
4. 6回連続一致で確定 → 開または閉を実行 → 再スリープ

### 開閉動作
- **開**: リレー正転（GPIO26=HIGH）→ ドラムがワイヤー巻上げ → ホールカウントが規定値に達したら停止。過電流／タイムアウトで異常停止。セルフロックで無通電保持
- **閉**: リレー逆転（GPIO27=HIGH）→ 登録ゼロ点ぴったりまで繰り出し → 蓋は自重で着座

### 位置管理
- 現在位置は**RTCメモリ**（ディープスリープを跨いで保持、電源断・ENリセットで消える）
- 全開回転数は**NVS（フラッシュ）**に保存（電源断でも保持）
- 位置を失った場合（電源断・動作失敗）は**CALIBモード**に入り、人が再登録する

### CALIBモード（設置時・電源断復帰時）
1. LEDゆっくり点滅＝登録待ち
2. 蓋を着座させ弛みを取る → **10秒放置** → 速点滅×3＝ゼロ点登録
3. **開方向のジョグのみ**で全開位置へ → 10秒放置 → 速点滅×5＝全開位置をNVS保存
4. 自動で全閉まで戻して通常運用へ
5. 30分無操作で**LED消灯・完全停止**（復帰は電源再投入のみ）

### LEDの意味論
| 表示 | 意味 |
|---|---|
| BOOTボタン押下→点灯 | 正常（操作受付中） |
| 点灯しっぱなし | 動作中（開閉・検証中） |
| ゆっくり点滅 | CALIB待機（位置登録を求めている） |
| **BOOTを押しても消灯のまま** | **異常**（電源喪失／ファーム停止／CALIB放置） |

### 手動操作
- **電動**: ボックスを開け、BOOTポチ→LED点灯中にトグルSWで開/閉
- **非常時**: ワイヤーを外して蓋を直接操作、またはユニット引き抜きでベニヤ運用に復帰

## ドラム設計ルール

1. φ40基準（1回転≒126mm繰り出し）。**ストローク調整はドラム径ではなく回転数（ファーム定数）で行う**
2. 一層巻き厳守: ドラム幅は必要巻き数×1.6mm＋余裕
3. ワイヤー固定は穴通し＋裏結び。固定穴はドラム端に寄せ、**軸正面視で時計回り＝巻き取り**になる向きに巻く
4. ドラムはフランジハブとM3×4本で共締め、軸根元側に寄せる
5. **磁石4個を側面に90°等配**（S極外向き）。センサは側面に正対・ギャップ3〜4mm
6. 組立後に手回しで**1回転＝4カウント**を確認してからセンサ位置を本固定

## 設計ルール（ゲート部）

1. 摺動はコの字レール内（塩ビ×塩ビ）のみ。コンクリには触れない。クリアランス片側1〜2mm
2. ストローク＝開口高＋20mm。プレートは溝上端より背高（保持はレール）
3. 引上げ力見積り: 蓋自重≒20N＋座面摩擦≒13N＝約35N ⇒ ドラム半径2cmで必要トルク≒7kgf·cm
4. 卓上試験の合格基準: **ワイヤーを離すと蓋が自重でスッと落ち切ること**
5. 春の設置時に摺動面へ蝋を塗布

## ボックス内配置ルール

1. バッテリーは**縦立て（65×94mmを底面・端子は上側前面）**。倒立のみ禁止。結束バンド上下2本＋底に滑り止め
2. 端子の露出金属は必ず絶縁（横向き端子は接触リスクが増える）
3. モータ＋ドラムはバッテリー上部。ワイヤーは左壁沿いを垂直降下してVP13ノズルへ
4. **ワイヤー経路とノズル位置は組立時に実物で最終調整**（本設計唯一の綱渡り箇所）
5. 電子基板は上段〜中段（結露自衛）。ノズルには防虫の詰め物
6. DROKは基板に載せず単体固定。**トリマに配線が触れない向き**で貼る

## 現地実測が必要な項目（組立前）

1. 升の開口部の縦横寸法 → プレート開口・蓋寸法
2. 既存溝の幅 → プレート板厚（t=10）の適合確認
3. 溝上端から木材までの高さ → ワイヤー長・プレート上端高さ
4. 既存木材の位置・強度 → ボックス取付方法
5. 電極設置位置〜取水口の距離 → ケーブル長
6. ソーラー南向き設置の可否（影の確認）
