# 田圃水管理ロボット

田んぼの水位を電極センサで監視し、升のスライドゲートをワイヤー巻き取り式で自動開閉する自作ロボットのリポジトリです。
ESP32 が 10 分周期のディープスリープで低消費電力に動作し、ソーラー独立電源で稼働します。現地では LED と押しボタンだけで状態確認・手動操作・キャリブレーションができます。

| 項目 | 内容 |
|---|---|
| ファームウェア | **v0.4.0**(LittleFS ログ版) |
| 制御ボード | Freenove ESP32-WROOM-32E 38pin / Arduino IDE |
| 水位検出 | 電極式(上=止水位 / 下=開始水位 / 共通 GND の 3 本) |
| ゲート駆動 | 12V 10RPM ウォームギヤモータ + リレー H ブリッジ + ドラム巻き取り |
| 位置検出 | A3144 ホールセンサ + ドラム側面のネオジム磁石 4 個(1 カウント = 1/4 回転 ≒ 31.5mm) |
| 保護 | ACS712-5A 電流センサによる JAM 検出 + タイムアウト |
| 電源 | 12V 7.2Ah 鉛蓄電池 + 10W ソーラー + PWM チャーコン + DROK 降圧(5.06V) |
| 部品総額 | 約 ¥35,600(予備品込み。正味 ¥25,000〜27,000) |

## システム構成

```
 ソーラー10W ─► PWMチャーコン ─► LOAD ─► 12Vバス ─┬─► DROK(5.06V) ─► 5Vバス ─► ESP32 / リレーコイル / センサ
                    │                             └─► ACS712 ─► リレーNO ─► モータ ─► ドラム ─► ワイヤー ─► ゲート蓋
                  バッテリー 12V 7.2Ah(ヒューズ5A)

 電極(上/下/GND) ─► GPIO36/39      ホールセンサ ─► GPIO35      手動SW ─► GPIO33(開)/13(閉)      BOOT ─► GPIO0(起床)
```

- **開**: リレー正転でドラムがワイヤーを巻き上げ、ホールカウントが登録全開値に達したら停止。ウォームギヤのセルフロックで無通電保持。
- **閉**: リレー逆転で登録ゼロ点ぴったりまで繰り出し、蓋は自重で着座。繰り出し量が固定なので巻き戻り(ワイヤー逆巻き)が構造的に起きない。
- **位置管理**: 現在位置は RTC メモリ(ディープスリープ跨ぎで保持、電源断・EN リセットで消える)、全開カウントは NVS(電源断でも保持)。

## 動作フロー(ファームウェア)

```
起床(10分タイマー or BOOTボタン)
  └→ 5秒の操作受付ウィンドウ(LED点灯)
       ├ 開SW → 全開まで駆動 → スリープ
       ├ 閉SW → 全閉まで駆動 → スリープ
       └ 操作なし → 電極で水位判定
            ├ 現在の開閉状態と要求が一致 → スリープ
            └ 不一致 → 10秒間隔×6回の再確認(VERIFY)
                 ├ 途中で判定が反転 → キャンセルしてスリープ
                 └ 6回連続一致 → 開閉実行 → スリープ
```

- **水位判定**: 上電極が濡れていれば「水位高 → 閉」、下電極が乾いていれば「水位低 → 開」、中間帯は現状維持。電極は電食防止のため測定時のみ GPIO4 から通電します。
- **失敗時**: 過電流(JAM)やタイムアウトで開に失敗すると 1 カウント繰り出して張力を抜き、位置情報を破棄して再起動 → CALIB モードへ。閉のタイムアウトは着座後の空転とみなして正常扱いです。
- **スリープ**: `gpio_hold` でリレー入力ピンを OFF レベルに固定し、スリープ中のチャタリングを防ぎます。タイマー起床と BOOT ボタン(ext0)起床は区別しません。

## イベントログ(LittleFS)

イベントを LittleFS の `/gate.csv` に追記します。RTC モジュールなしで運用するため、時刻列は**電源投入からの経過秒**です(ESP32 のシステム時刻はディープスリープ中も RTC スロークロックで進むので、起床・スリープをまたいだ通し時間になります。10 分寝れば 600 秒進みます。これは ESP32 のシステム時刻が RTC で保持される仕様に依るもので、初回の実機ダンプで `BOOT,timer` 行の間隔が ≈600 になることを確認してください)。1 行約 40 バイト、10 分周期で 1 日約 6KB、上限 1MB で約 170 日 = 1 シーズン分。上限に達すると追記を止めます(消去は `x`)。

```
秒,イベント,フィールド...
0,BOOT,cold,-1,0            # 起床要因(cold/timer/button/reset), 位置, 全開回転数
605,CYCLE,2450,1830,0,keep  # 上電極ADC, 下電極ADC, 位置, 判定(open/close/keep)
1210,VERIFY,confirmed,6     # 連続一致回数
1230,VERIFY,cancel,3,2500,2480  # 反転した回, そのときの上ADC, 下ADC
1272,OPEN,ok,0,12,1970      # 結果(ok/jam/timeout), 開始位置, ホールカウント, ACS値(-1=未測定)
1290,RETREAT,ok,0,1,1966    # 開失敗後の張力抜き(1カウント繰り出し)
1900,CLOSE,timeout,12,12,1968
2500,MANUAL,open,0          # 手動SW, 位置(続けて OPEN/CLOSE 行が出る)
3100,ERASE
```

CALIB 系: `CALIB,enter,位置,全開回転数` / `CALIB,jog,open|close,カウント,累積` / `CALIB,zero` / `CALIB,open,回転数` / `CALIB,invalid,累積` / `CALIB,done,位置` / `CALIB,timeout`

**読み出し**: USB でシリアルモニタ(115200bps)を開く → BOOT ボタンで起床 → LED 点灯中の 5 秒窓の間に 1 文字送信。コマンドを処理するたびに窓が 5 秒延長されるので、ダンプ中に窓が閉じることはありません。
本体を持ち帰って PC の USB から給電した場合は RTC メモリが消えて CALIB モード(LED ゆっくり点滅)で起動しますが、CALIB 中も同じコマンドを受け付けます(操作なしなら 30 分でタイムアウト停止)。
ログは LittleFS パーティションにあるので、スケッチを書き直しても消えません(Arduino IDE の「Erase All Flash Before Sketch Upload」を有効にした場合とパーティションスキームを変えた場合は消えます)。

| コマンド | 動作 |
|---|---|
| `d` | `/gate.csv` を `--- BEGIN` 〜 `--- END` で挟んでダンプ |
| `i` | 使用量・残量(残日数の目安)・経過秒を表示 |
| `x` | ログを消去。誤タイプ対策で **`x` を 2 回連続** で送る(1 回目は確認メッセージのみ)。直後に `ERASE` 行が記録される |

## LED の意味

| LED の状態 | 意味 |
|---|---|
| BOOT ボタン押下で点灯(5 秒) | 正常。操作受付ウィンドウ中 |
| 点灯しっぱなし | 動作中(開閉・水位再確認中) |
| ゆっくり点滅(1 秒周期) | CALIB 待機中(位置登録を求めている) |
| 速い点滅 ×3 | CALIB: ゼロ点(全閉)を登録した |
| 速い点滅 ×5 | CALIB: 全開位置を登録した(NVS 保存) |
| 速い点滅 ×10 | CALIB: 全開位置が無効(0 以下)。やり直し |
| **BOOT を押しても消灯のまま** | **異常**(電源喪失 / ファーム停止 / CALIB 放置タイムアウト) |

## ボタン操作

| ボタン | 役割 |
|---|---|
| BOOT(GPIO0) | スリープ中の即時起床・生存確認。LED 点灯中の 5 秒間が操作受付ウィンドウ |
| 手動トグル SW(モーメンタリ (ON)-OFF-(ON)) | ウィンドウ中: 全開 / 全閉まで駆動。CALIB 中: 押している間だけジョグ |
| EN | **使用しない**。ハードリセットで RTC メモリが消え、CALIB 要求になる |

- 手動 SW はボックス内蔵(非防水)。操作時はボックスを開け、BOOT を押して LED 点灯中に SW を倒します。
- 非常時はワイヤーを外して蓋を直接操作するか、ユニットを引き抜いてベニヤ運用に戻します。
- ⚠ BOOT を押したまま EN / 電源投入すると書き込みモードに入ります。
- ⚠ 手動 SW にオルタネート型(MTS-103 等)は不可。倒し忘れで事故になります。

## CALIB(キャリブレーション)モード

以下の場合、起動時に自動で CALIB モードに入ります。

- 初回起動、または全開カウントが未登録
- ファーム書き込み・EN リセット・電源断で RTC メモリが消えた(**書き込み後は毎回 CALIB 再登録が必要**)
- 前回の開閉に失敗して位置が不定になった

### 手順

1. LED がゆっくり点滅している状態で、SW を倒している間だけモーターがジョグ駆動します。
2. **蓋を着座させ弛みを軽く取って 10 秒放置** → 速い点滅 ×3 でゼロ点が確定します。
3. **開方向のジョグのみ**で全開位置へ → 10 秒放置 → 速い点滅 ×5 で全開カウントが NVS に保存されます。
4. 自動で全閉まで繰り出して通常運用へ移行します。

### 運用ルール

- 開閉を往復すると累積カウントが相殺されて `invalid open position` になります。行き過ぎたら電源を入れ直してゼロ点からやり直してください。
- ジョグはなるべく少ない回数(理想は 1 回押しっぱなし)で行ってください。押すたびにカウンタが 0 から数え直すため、分解能由来の誤差が積もります。
- 30 分間無操作が続くと LED を消灯して完全停止します(復帰は電源再投入のみ)。

## GPIO 割当

詳細な結線は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) を参照してください。Freenove 38pin はシルク配置が独自なので、番号ではなく**シルク印字**を正として配線します。

| GPIO | 方向 | 接続先 | 備考 |
|---|---|---|---|
| 26 | 出力 | リレー IN1(巻上げ / 開) | **HIGH で ON** |
| 27 | 出力 | リレー IN2(繰出し / 閉) | **HIGH で ON** |
| 25 | 出力 | ホールセンサ電源(S8050 ベース、1kΩ 経由) | 測定時のみ ON |
| 35 | 入力 | A3144 ホールセンサ OUT | 外部 100kΩ プルアップ → 3V3。FALLING で 1 カウント |
| 34 | ADC1 | ACS712 OUT(10k:20k 分圧後) | 11dB 減衰 |
| 33 / 13 | 入力 | 手動 SW 開 / 閉 | INPUT_PULLUP。COM は GND |
| 4 | 出力 | 電極測定電源(100kΩ×2 の駆動元) | 測定時のみ HIGH |
| 36(VP) | ADC1 | 上電極(止水位) | 入力専用 |
| 39(VN) | ADC1 | 下電極(開始水位) | 入力専用 |
| 2 | 出力 | 内蔵 LED | 出力専用として使用 |
| 0 | 入力 | BOOT ボタン | ext0 起床 |

## ファームウェア定数と実測値

ソース冒頭の定数で調整します。実測値の根拠は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) の「部品の実測値まとめ」を参照してください。

| 定数 | 値 | 説明 |
|---|---|---|
| `BENCH_MODE` | `0` | `1` で卓上試験モード(シリアルで水位指令) |
| `ACS_IDLE` | `1965` | ACS712 停止時 ADC(実測。回転中は 1890 でマイナス方向の差 75) |
| `ACS_JAM_DELTA` | `150` | JAM 判定閾値(回転中の差 75 に対し 2 倍のマージン) |
| `MS_PER_TURN` | `1500` ms | 1 カウントあたりの想定時間(実測パルス間隔 約 1300ms) |
| `TURN_TIMEOUT_MARGIN` | `4000` ms | 駆動タイムアウトの余裕(突入マスク・磁石到達までの空白を吸収) |
| `SLEEP_US` | 10 分 | スリープ周期 |
| `SW_WINDOW_MS` | `5000` ms | 起床後の手動 SW 受付時間 |
| `VERIFY_COUNT` / `VERIFY_INTERVAL_MS` | `6` / `10000` ms | 状態変更前の再確認回数と間隔 |
| `WATER_ADC_THRESHOLD` | `2000` | 電極 WET/DRY 閾値(露出 4095 / 水没 0〜312 の中間) |
| `CALIB_CONFIRM_MS` | `10000` ms | CALIB での放置確定時間 |
| `CALIB_TIMEOUT_MS` | 30 分 | CALIB 無操作での完全停止時間 |

> 注: ソースでは変数名が `turns` ですが、磁石 4 個構成では **1 カウント = 1/4 回転**です。

## ビルド・書き込み

1. Arduino IDE に ESP32 ボードパッケージをインストールします(`Preferences.h` は同梱)。
2. ボードに「ESP32 Dev Module」を選択し、**Upload Speed = 115200** にします(921600 は失敗します)。
3. `water_gate_firmware_v0_3_1_dbg.ino` を書き込みます。
4. シリアルモニタを **115200 bps** で開くと `[CYCLE]` `[VERIFY]` `[CALIB]` `[JOG]` `[ELEC]` `[OPEN]` `[CLOSE]` の診断ログが確認できます。
5. 書き込みで RTC メモリが消えるため、起動後は CALIB モードから始まります。

### 卓上試験(BENCH_MODE)

`#define BENCH_MODE 1` にすると電極の代わりにシリアル入力で水位を指令できます。

- `l` : 水位低(開けたい)
- `h` : 水位高(閉でよい)

指令は起床時の操作受付ウィンドウ後に読み取られ、RTC メモリに保持されます。

## ハードウェア立ち上げ手順(要約)

安全順序の詳細は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) の「立ち上げ手順」を参照してください。

1. バッテリー + ヒューズ + DROK のみ接続し、**VOUT が 5.0V 付近であることを実測**(設定違いのまま ESP32 に繋ぐと即死)
2. ESP32 単体を USB で起動し、L チカでボード確認
3. リレー接続(JD-VCC ジャンパ除去 → VCC = 3V3 / JD-VCC = 5V)、GPIO26/27 でカチカチ音を確認(モータ未接続)
4. モータ接続 → 真理値表どおりに正転 / 逆転 / 停止を確認。**誘導性負荷のためジャンパの仮当ては禁止**
5. ACS712 の停止 / 回転中 ADC を記録 → ファーム定数へ
6. ホールセンサ + 磁石でカウント確認(**S 極が検出面**。反応しなければ磁石を裏返す)

配線作法: 繋ぐときはマイナス先 → プラス後、外すときは逆。ヒューズをマスタースイッチとして使い、＋系の露出金属は必ず絶縁してから − 側を接続します(短絡による焼損事例あり)。

## 変更履歴

- **v0.3.1**: 生存確認 / 即時起床を BOOT ボタン(GPIO0, ext0 起床)に変更。EN ボタンは RTC メモリが消えるため不使用に。
- **v0.3**: 心拍方式を廃止しスリープ 10 分周期に統合。起床時 5 秒の操作受付ウィンドウを追加。`gpio_hold` でスリープ中のリレー浮きを固定。
- **v0.2.1**: ホールセンサ電源 ON 時の偽エッジ(+1)対策。
- **v0.2**: 自動ホーミングを廃止し CALIB モードを導入。繰り出しは常に登録済みゼロ点までとし巻き戻り問題を構造的に解消。全開カウントを NVS 保存。
