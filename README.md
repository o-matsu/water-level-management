# 田圃水管理ロボット

田んぼの水位を電極センサで監視し、升のスライドゲートをワイヤー巻き取り式で自動開閉する自作ロボットのリポジトリです。
ESP32 が 10 分周期のディープスリープで低消費電力に動作し、ソーラー独立電源で稼働します。現地では LED と押しボタンだけで状態確認・手動操作・キャリブレーションができます。

| 項目 | 内容 |
|---|---|
| ファームウェア | **v0.5.3**(ハイブリッド位置制御版) |
| 制御ボード | Freenove ESP32-WROOM-32E 38pin / Arduino IDE |
| 水位検出 | 電極式(高さをずらした電極 A/B + 共通 GND の 3 本。判定は対称で上下の区別なし) |
| ゲート駆動 | 12V 10RPM ウォームギヤモータ + リレー H ブリッジ + ドラム巻き取り |
| 位置検出 | A3144 ホールセンサ + ドラム側面のネオジム磁石 4 個(1 カウント = 1/4 回転 ≒ 31.5mm)。エッジ間は実測速度で時間補間し 1/1000 カウント単位で管理 |
| 保護 | ACS712-5A 電流センサによる JAM 検出 + タイムアウト |
| 電源 | 12V 7.2Ah 鉛蓄電池 + 10W ソーラー + PWM チャーコン + DROK 降圧(5.06V) |
| 部品総額 | 約 ¥35,600(予備品込み。正味 ¥25,000〜27,000) |

## システム構成

```
 ソーラー10W ─► PWMチャーコン ─► LOAD ─► 12Vバス ─┬─► DROK(5.06V) ─► 5Vバス ─► ESP32 / リレーコイル / センサ
                    │                             └─► ACS712 ─► リレーNO ─► モータ ─► ドラム ─► ワイヤー ─► ゲート蓋
                  バッテリー 12V 7.2Ah(ヒューズ5A)

 電極(A/B/GND) ─► GPIO36/39       ホールセンサ ─► GPIO35      手動SW ─► GPIO33(開)/13(閉)      BOOT ─► GPIO0(起床)
```

- **開**: リレー正転でドラムがワイヤーを巻き上げ、位置が登録全開値に達したら停止。ウォームギヤのセルフロックで無通電保持。
- **閉**: リレー逆転で登録ゼロ点の 1mm 手前(`CLOSE_BIAS_MC`)まで繰り出し、蓋は自重で着座。繰り出し量が固定なので巻き戻り(ワイヤー逆巻き)も弛み(蓋の傾き)も構造的に起きない。
- **位置管理(v0.5.0〜)**: 位置は mc(1/1000 カウント)単位。開は FALLING、閉は RISING エッジを数えることで、方向によらず磁石の同じ側(整数カウント位置)で同期し、エッジ間は直近の実測速度(方向別に学習、ms/カウント)で時間補間します。磁石の検出幅も学習し、反対側のエッジでも再同期するので、閉の最終区間の補間距離は検出幅(数 mm)まで縮みます。リレー投入直後 300ms のエッジと、推定位置から 350mc 以上離れたエッジは偽エッジとして無視します。現在位置と学習速度は RTC メモリ(ディープスリープ跨ぎで保持、電源断・EN リセットで消える)、全開位置と学習速度のコピーは NVS(電源断でも保持)。

## 動作フロー(ファームウェア)

```
起床(10分タイマー or BOOTボタン)
  └→ 5秒の操作受付ウィンドウ(LED点灯)
       ├ 開SW → 全開まで駆動 → スリープ
       ├ 閉SW → 全閉まで駆動 → スリープ
       └ 操作なし → 電極で水位判定
            ├ 現在の開閉状態と要求が一致 → スリープ
            └ 不一致 → 10秒間隔×6回の再確認(VERIFY)
                 ├ 途中で判定が反転 → キャンセルしてスリープ
                 └ 6回連続一致 → 開閉実行 → スリープ
```

- **水位判定**: 濡れている電極の本数だけで判定します — 2 本「水位高 → 閉」、0 本「水位低 → 開」、1 本(中間水位・水膜・断線等)は現状維持。上下対称なので電極 2 本の取り付け・配線の上下はどちらでもかまいません。電極は電食防止のため測定時のみ GPIO4 から通電します。
- **失敗時**: 過電流(JAM)やタイムアウトで開に失敗すると 1 カウント繰り出して張力を抜き、位置情報を破棄して再起動 → CALIB モードへ。閉のタイムアウトは着座後の空転とみなして正常扱いです(ただしホールパルスが 1 つも来ないタイムアウトはセンサ無応答として位置を破棄します)。
- **スリープ**: `gpio_hold` でリレー入力ピンを OFF レベルに固定し、スリープ中のチャタリングを防ぎます。タイマー起床と BOOT ボタン(ext0)起床は区別しません。

## イベントログ(LittleFS)

イベントを LittleFS の `/gate.csv` に追記します。RTC モジュールなしで運用するため、時刻列は**電源投入からの経過秒**です(ESP32 のシステム時刻はディープスリープ中も RTC スロークロックで進むので、起床・スリープをまたいだ通し時間になります。10 分寝れば 600 秒進みます。これは ESP32 のシステム時刻が RTC で保持される仕様に依るもので、初回の実機ダンプで `BOOT,timer` 行の間隔が ≈600 になることを確認してください)。1 行約 40 バイト、10 分周期で 1 日約 6KB、上限 1MB で約 170 日 = 1 シーズン分。上限に達すると追記を止めます(消去は `x`)。

```
秒,イベント,フィールド...
0,BOOT,cold,-1,3150             # 起床要因(cold/timer/button/reset), 位置mc(-1=不定), 全開mc
605,CYCLE,2450,1830,30,keep     # 電極A(VP)ADC, 電極B(VN)ADC, 位置mc, 判定(open/close/keep)
1210,VERIFY,confirmed,6         # 連続一致回数
1230,VERIFY,cancel,3,2500,2480  # 反転した回, そのときのA ADC, B ADC
1272,OPEN,ok,30,3150,3,1280,240,1994   # 結果(ok/jam/timeout), 開始mc, 終了mc, 計数エッジ数, 学習速度ms/カウント, 磁石検出幅mc(0=未学習), ACS値(-1=未測定)
1290,RETREAT,ok,2100,1100,1,1280,240,1966  # 開失敗後の張力抜き(1カウント繰り出し)
1900,CLOSE,ok,3150,30,3,1250,240,1983
2500,MANUAL,open,30             # 手動SW, 位置mc(続けて OPEN/CLOSE 行が出る)
3100,ERASE
```

位置の単位 mc は 1/1000 カウント(1 カウント ≒ 31.5mm なので 1mc ≒ 0.03mm)。
CALIB 系: `CALIB,enter,位置mc,全開mc` / `JOG,ok|jam,開始mc,終了mc,エッジ数,ms/カウント,検出幅mc,ACS値` / `CALIB,zero` / `CALIB,open,全開mc,閉速度,開速度,検出幅mc` / `CALIB,invalid,位置mc` / `CALIB,done,位置mc` / `CALIB,timeout`

**読み出し**: USB でシリアルモニタ(115200bps)を開く → BOOT ボタンで起床 → LED 点灯中の 5 秒窓の間に 1 文字送信。コマンドを処理するたびに窓が 5 秒延長されるので、ダンプ中に窓が閉じることはありません。
本体を持ち帰って PC の USB から給電した場合は RTC メモリが消えて CALIB モード(LED ゆっくり点滅)で起動しますが、CALIB 中も同じコマンドを受け付けます(操作なしなら 30 分でタイムアウト停止)。
ログは LittleFS パーティションにあるので、スケッチを書き直しても消えません(Arduino IDE の「Erase All Flash Before Sketch Upload」を有効にした場合とパーティションスキームを変えた場合は消えます)。

| コマンド | 動作 |
|---|---|
| `d` | `/gate.csv` を `--- BEGIN` 〜 `--- END` で挟んでダンプ |
| `i` | 使用量・残量(残日数の目安)・経過秒を表示 |
| `x` | ログを消去。誤タイプ対策で **`x` を 2 回連続** で送る(1 回目は確認メッセージのみ)。直後に `ERASE` 行が記録される |

## LED の意味

| LED の状態 | 意味 |
|---|---|
| BOOT ボタン押下で点灯(5 秒) | 正常。操作受付ウィンドウ中 |
| 点灯しっぱなし | 動作中(開閉・水位再確認中) |
| ゆっくり点滅(1 秒周期) | CALIB 待機中(位置登録を求めている) |
| 速い点滅 ×3 | CALIB: ゼロ点(全閉)を登録した |
| 速い点滅 ×5 | CALIB: 全開位置を登録した(NVS 保存) |
| 速い点滅 ×10 | CALIB: 全開位置が無効(ゼロ点から 0.5 カウント未満)、またはジョグ中に過電流(JAM)で自動停止。やり直し |
| **BOOT を押しても消灯のまま** | **異常**(電源喪失 / ファーム停止 / CALIB 放置タイムアウト)。CALIB 放置タイムアウト後は BOOT でも起きません。復帰は電源再投入のみ |

## ボタン操作

| ボタン | 役割 |
|---|---|
| BOOT(GPIO0) | スリープ中の即時起床・生存確認。LED 点灯中の 5 秒間が操作受付ウィンドウ |
| 手動トグル SW(モーメンタリ (ON)-OFF-(ON)) | ウィンドウ中および水位再確認(VERIFY)中: 全開 / 全閉まで駆動。CALIB 中: 押している間だけジョグ(過電流で自動停止) |
| EN | **使用しない**。ハードリセットで RTC メモリが消え、CALIB 要求になる |

- 手動 SW はボックス内蔵(非防水)。操作時はボックスを開け、BOOT を押して LED 点灯中に SW を倒します。
- 非常時はワイヤーを外して蓋を直接操作するか、ユニットを引き抜いてベニヤ運用に戻します。
- ⚠ BOOT を押したまま EN / 電源投入すると書き込みモードに入ります。
- ⚠ 手動 SW にオルタネート型(MTS-103 等)は不可。倒し忘れで事故になります。

## CALIB(キャリブレーション)モード

以下の場合、起動時に自動で CALIB モードに入ります。

- 初回起動、または全開カウントが未登録
- ファーム書き込み・EN リセット・電源断で RTC メモリが消えた(**書き込み後は毎回 CALIB 再登録が必要**)
- 前回の開閉に失敗して位置が不定になった

### 手順

1. LED がゆっくり点滅している状態で、SW を倒している間だけモーターがジョグ駆動します。
2. **蓋を着座させ弛みを軽く取って 10 秒放置** → 速い点滅 ×3 でゼロ点が確定します。
3. **開方向のジョグのみ**で全開位置へ → 10 秒放置 → 速い点滅 ×5 で全開カウントが NVS に保存されます。
4. 自動で全閉まで繰り出して通常運用へ移行します。

### 運用ルール

- 全開位置はゼロ点から 0.5 カウント以上開いた位置でないと `invalid open position` になります。行き過ぎたら閉方向にジョグして戻せます(v0.5.0 から往復しても位置は連続的に追跡されます)。
- ジョグ中も位置は mc 単位で追跡されるので、複数回に分けて押しても誤差は積もりません。ただし SW を離してから停止するまでの数十 ms 分は進みます。
- 30 分間無操作が続くと LED を消灯して完全停止します(復帰は電源再投入のみ)。

## GPIO 割当

詳細な結線は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) を参照してください。Freenove 38pin はシルク配置が独自なので、番号ではなく**シルク印字**を正として配線します。

| GPIO | 方向 | 接続先 | 備考 |
|---|---|---|---|
| 26 | 出力 | リレー IN1(巻上げ / 開) | **HIGH で ON** |
| 27 | 出力 | リレー IN2(繰出し / 閉) | **HIGH で ON** |
| 25 | 出力 | ホールセンサ電源(S8050 ベース、1kΩ 経由) | 測定時のみ ON |
| 35 | 入力 | A3144 ホールセンサ OUT | 外部 100kΩ プルアップ → 3V3。FALLING で 1 カウント |
| 34 | ADC1 | ACS712 OUT(10k:20k 分圧後) | 11dB 減衰 |
| 33 / 13 | 入力 | 手動 SW 開 / 閉 | INPUT_PULLUP。COM は GND |
| 4 | 出力 | 電極測定電源(100kΩ×2 の駆動元) | 測定時のみ HIGH |
| 36(VP) | ADC1 | 電極 A | 入力専用。判定は対称なので A/B の取り付け上下は不問 |
| 39(VN) | ADC1 | 電極 B | 入力専用 |
| 2 | 出力 | 内蔵 LED | 出力専用として使用 |
| 0 | 入力 | BOOT ボタン | ext0 起床 |

## ファームウェア定数と実測値

ソース冒頭の定数で調整します。実測値の根拠は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) の「部品の実測値まとめ」を参照してください。

| 定数 | 値 | 説明 |
|---|---|---|
| `BENCH_MODE` | `0` | `1` で卓上試験モード(シリアルで水位指令) |
| `ACS_IDLE` | `1965` | ACS712 停止時 ADC(実測。回転中は 1890 でマイナス方向の差 75) |
| `ACS_JAM_DELTA` | `150` | JAM 判定閾値(回転中の差 75 に対し 2 倍のマージン) |
| `MS_PER_COUNT_DEF` | `1300` ms | 1 カウントあたりの初期想定時間。駆動ごとに方向別に学習し RTC/NVS に保持 |
| `CLOSE_BIAS_MC` | `30` mc | 閉でゼロ点の手前に残す量(≒1mm)。弛みによる蓋の傾き防止 |
| `OPEN_MIN_MC` | `500` mc | 全開登録の最小値 |
| `TURN_TIMEOUT_MARGIN` | `4000` ms | 駆動タイムアウトの余裕(突入マスク・磁石到達までの空白を吸収) |
| `SLEEP_US` | 10 分 | スリープ周期 |
| `SW_WINDOW_MS` | `5000` ms | 起床後の手動 SW 受付時間 |
| `VERIFY_COUNT` / `VERIFY_INTERVAL_MS` | `6` / `10000` ms | 状態変更前の再確認回数と間隔 |
| `WATER_ADC_THRESHOLD` | `270` | 電極 WET/DRY 閾値。現場実測: 水没 116〜231 / 引き上げ直後の水膜 310〜1900(数時間かけて 4095 へ)。水膜を DRY 側に倒す |
| `CALIB_CONFIRM_MS` | `10000` ms | CALIB での放置確定時間 |
| `CALIB_TIMEOUT_MS` | 30 分 | CALIB 無操作での完全停止時間 |

> 注: 磁石 4 個構成では **1 カウント = 1/4 回転**です。

## ビルド・書き込み

1. Arduino IDE に ESP32 ボードパッケージをインストールします(`Preferences.h` は同梱)。
2. ボードに「ESP32 Dev Module」を選択し、**Upload Speed = 115200** にします(921600 は失敗します)。
3. クローンしたフォルダの `water-level-management.ino` を開いて書き込みます(フォルダ名を変えると開けなくなります。旧 Arduino IDE 1.x はハイフン付きスケッチ名を受け付けないため IDE 2.x を使ってください)。
4. シリアルモニタを **115200 bps** で開くと `[CYCLE]` `[VERIFY]` `[CALIB]` `[JOG]` `[ELEC]` `[LOG]` の診断ログが確認できます。
5. 書き込みで RTC メモリが消えるため、起動後は CALIB モードから始まります。LittleFS のログ(`/gate.csv`)と NVS の全開回転数は消えません。

### arduino-cli で書き込む場合

```sh
arduino-cli core install esp32:esp32
arduino-cli board list                        # ポート確認(例: /dev/cu.usbserial-110)
arduino-cli compile --fqbn esp32:esp32:esp32:UploadSpeed=115200 \
  -u -p /dev/cu.usbserial-110 .                 # リポジトリ直下で実行
```

- `UploadSpeed=115200` は必須です。デフォルトの 921600 では stub flasher 起動後の速度切替で `Unable to verify flash chip connection` になります(実機で確認済み)。
- `-u` を外せばコンパイルのみ。`BENCH_MODE` / `CALIB_DEBUG` を切り替えたビルドの検証にも使えます。
- 書き込み後の確認は `arduino-cli monitor -p /dev/cu.usbserial-110 -c baudrate=115200`(対話端末が必要)か、任意のシリアルモニタで `i` / `d` を送ります。

### 卓上試験(BENCH_MODE)

`#define BENCH_MODE 1` にすると電極の代わりにシリアル入力で水位を指令できます。

- `l` : 水位低(開けたい)
- `h` : 水位高(閉でよい)

指令は起床時の操作受付ウィンドウ中(および VERIFY 中)に `d`/`i`/`x` と同じ経路で読み取られ、RTC メモリに保持されます。

## ハードウェア立ち上げ手順(要約)

安全順序の詳細は [`doc/wiring-and-gpio.md`](doc/wiring-and-gpio.md) の「立ち上げ手順」を参照してください。

1. バッテリー + ヒューズ + DROK のみ接続し、**VOUT が 5.0V 付近であることを実測**(設定違いのまま ESP32 に繋ぐと即死)
2. ESP32 単体を USB で起動し、L チカでボード確認
3. リレー接続(JD-VCC ジャンパ除去 → VCC = 3V3 / JD-VCC = 5V)、GPIO26/27 でカチカチ音を確認(モータ未接続)
4. モータ接続 → 真理値表どおりに正転 / 逆転 / 停止を確認。**誘導性負荷のためジャンパの仮当ては禁止**
5. ACS712 の停止 / 回転中 ADC を記録 → ファーム定数へ
6. ホールセンサ + 磁石でカウント確認(**S 極が検出面**。反応しなければ磁石を裏返す)

配線作法: 繋ぐときはマイナス先 → プラス後、外すときは逆。ヒューズをマスタースイッチとして使い、＋系の露出金属は必ず絶縁してから − 側を接続します(短絡による焼損事例あり)。

## 変更履歴

- **v0.5.3**: 電極を上下(hi/lo)ではなく対称な A(VP)/B(VN) として扱うように変更。判定は濡れ本数(2 本=閉 / 0 本=開 / 1 本=維持)で、取り付け・配線の上下を問わない。2026-09-02 撤収までの現場ログで電極が物理的に上下逆でも問題ないことを確認したための整理(ログの列構造は不変)。
- **v0.5.2**: 一晩の現場運用ログから電極閾値を 270 に(水膜を WET と誤判定し、水位低下後もゲートが開かなかった)。上のみ濡れの矛盾状態は現状維持に。磁石位相を学習し、任意のゼロ点でもエッジ同期が確実に効くように。
- **v0.5.1**: 現場ログでリレー投入時の偽エッジが毎回混入し速度学習を汚していた(→ 閉が数 mm 手前で停止)ため、突入マスク中のエッジ破棄・推定位置から遠いエッジの棄却・学習間隔の妥当範囲を追加。磁石検出幅を学習し B 側エッジでも再同期。
- **v0.5.0**: 位置管理をハイブリッド(ホールエッジ同期 + 時間補間、mc 単位)に変更。開は FALLING / 閉は RISING を数えて方向による停止位置差を解消。閉はゼロ点 1mm 手前で停止して弛みを防止。CALIB の位置も mc 精度で登録。ログの OPEN/CLOSE/JOG 行の形式変更。
- **v0.4.0**: LittleFS イベントログ(`/gate.csv`、経過秒付き)とシリアルコマンド `d`/`i`/`x` を追加。CALIB ジョグの JAM 監視、ホールパルスなし CLOSE タイムアウトの位置喪失扱い、電極の 1 回通電両読み、VERIFY 中の手動 SW 受付。
- **v0.3.1**: 生存確認 / 即時起床を BOOT ボタン(GPIO0, ext0 起床)に変更。EN ボタンは RTC メモリが消えるため不使用に。
- **v0.3**: 心拍方式を廃止しスリープ 10 分周期に統合。起床時 5 秒の操作受付ウィンドウを追加。`gpio_hold` でスリープ中のリレー浮きを固定。
- **v0.2.1**: ホールセンサ電源 ON 時の偽エッジ(+1)対策。
- **v0.2**: 自動ホーミングを廃止し CALIB モードを導入。繰り出しは常に登録済みゼロ点までとし巻き戻り問題を構造的に解消。全開カウントを NVS 保存。
